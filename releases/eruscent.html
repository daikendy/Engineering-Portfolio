Eruscent — institutional peer tutoring platform

spring boot · java · next.js · postgres eruscent.com ↗

Eruscent is a production-grade, multi-tenant B2B SaaS platform connecting university students with peer tutors. It's built around a strict institutional hierarchy — university, campus, department, user — with tenant boundaries enforced at both the database and service layer, not just the UI.

Architecture

The backend is a Spring Boot 3 service on Java 21, with PostgreSQL for storage and Flyway managing schema evolution. The frontend is Next.js with TypeScript and Tailwind. Identity is offloaded to Clerk as a stateless JWT/JWKS provider, with just-in-time user provisioning so accounts self-heal rather than requiring manual sync.

What it does

  • Domain-gated signup: registration is restricted in real time to a super-admin-managed allowlist of verified university email domains.
  • Dual session engine: supports both 1:1 tutoring bookings and multi-student group lobbies, with real-time schedule-conflict prevention and optimistic-locking concurrency guards to stop double-booking under concurrent seat claims.
  • Zero-trust messaging: in-session peer chat is scoped to active participants only, with access revoked dynamically as enrollment changes.
  • Verified reviews and gamification: review submission is gated to completed sessions with anti-self-review checks, and a timezone-aware streak system tracks active engagement for students and tutors.
  • Security posture: OWASP-hardened, with a multi-subdomain CORS matrix, per-IP rate limiting via Bucket4j, and a tamper-evident audit log with digital signatures on sensitive actions.
