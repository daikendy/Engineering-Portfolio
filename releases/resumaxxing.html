v3.2.0 — Release

ResuMaxxing — an AI career operating system

next.js · fastapi · openai · postgres resumaxxing.tech ↗

ResuMaxxing is a career operating system built for high-velocity resume tailoring, job application tracking, and AI-driven document review. It's a decoupled, client-server architecture designed to move fast without sacrificing the guardrails that matter when AI is touching someone's actual resume.

Architecture

The frontend runs on Next.js App Router with React, TypeScript, and Tailwind, wrapped in Capacitor to ship the same codebase to web, iOS, and Android. The backend is an asynchronous FastAPI service on Python, using SQLAlchemy 2.0 with async drivers and Alembic for schema migrations — built to handle concurrent requests without thread-pool starvation.

What it does

  • AI-driven tailoring: GPT-4o and GPT-4o-mini power resume tailoring, guest bullet optimization, and skill-gap extraction against a target job description.
  • Anti-hallucination guardrails: strict JSON-schema enforcement, exact input-to-output bullet matching, and explicit prompt constraints that forbid introducing unstated skills, technologies, or metrics.
  • Document engine: pdfplumber and python-docx handle resume parsing and DOCX export, avoiding expensive vector-layout parsing that can freeze on complex PDFs.
  • Auth: Clerk-based identity with RSA JWKS keys fetched and cached once at startup, so token verification runs locally at CPU-microsecond speed instead of round-tripping to an auth server on every request.
  • Billing: Lemon Squeezy webhooks verified with constant-time HMAC SHA-256 signatures, driving tiered access (premium_1, premium_2) through idempotent background workers.
