ResuMaxxing — an AI career operating system

An end-to-end platform for resume tailoring, application tracking, and AI-driven document review. Decoupled Next.js frontend and async FastAPI backend, with GPT-4o handling tailoring and skill-gap analysis under strict anti-hallucination guardrails, Clerk-based auth with locally cached JWKS verification, and HMAC-signed billing via Lemon Squeezy. Ships to web and mobile from a single Capacitor-wrapped codebase.

Eruscent — institutional peer tutoring platform

A multi-tenant B2B SaaS connecting universities, departments, students, and tutors, with tenant isolation enforced down to the department level. Handles 1:1 and group session booking with optimistic-locking conflict prevention, zero-trust peer messaging, verified review aggregation, and timezone-aware gamification streaks — all behind an OWASP-hardened Spring Boot backend with full OpenAPI docs and automated CI/CD.

About

I'm Kenneth — an engineer who cares more about the shape of a problem than the framework used to solve it.

Over the last six years I've moved between infrastructure and product work, usually landing wherever a system needs to be made simpler before it can be made bigger. I like small teams, clear ownership, and writing code that a stranger could read at 2am during an incident and understand in thirty seconds.

Outside of work I run long distances slowly, read more nonfiction than I finish, and keep a running changelog of what I'm learning — you're looking at it.
