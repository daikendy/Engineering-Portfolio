Hardware Architecture

How I approach hardware-software co-design, memory constraints, and bus latency.

Building embedded systems requires thinking in cycles, bytes, and voltage states. Every line of C code maps directly to MCU registers, and every Verilog module translates into physical logic gates.

Hardware Principles

Guiding principles for embedded systems and hardware engineering.

01
Silicon logic doesn't lie — verify with waveforms early.
Before flashing to hardware, simulate Verilog logic with iVerilog and inspect timing diagrams in GTKWave to catch race conditions and setup/hold violations.
02
Respect hardware memory constraints & interrupt budgets.
Keep Interrupt Service Routines (ISRs) short and deterministic. Offload data transfers to DMA buffers to leave CPU cycles free for application logic.
